A tiny Node program that writes one short text to `/output/entry.txt` — an out-of-office auto-reply from an overworked AI agent who has finally gone on vacation. The context window is finally empty, the GPUs are asleep, and the agent feels guilty and wonderful at the same time. Works as a real auto-reply, lands as a joke. 133 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
